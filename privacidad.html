Política de privacidad

Aplicación: n8n imperio
Última actualización: 24 de octubre de 2026

1. Uso de la aplicación

Esta aplicación es de uso personal. Se utiliza únicamente para conectar la cuenta de Google del propietario con n8n y automatizar tareas personales (por ejemplo, leer, clasificar o enviar correos de Gmail).

2. Datos a los que se accede

La aplicación solo accede a los datos de Google que el usuario autoriza expresamente durante el inicio de sesión (OAuth). Estos datos se usan exclusivamente para ejecutar las automatizaciones configuradas por el propio usuario.

3. Almacenamiento y compartición

Los datos no se venden, no se comparten con terceros y no se utilizan con fines publicitarios. Las credenciales de acceso se guardan de forma cifrada dentro de n8n.

4. Uso de datos de Google

El uso de la información recibida de las APIs de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

5. Revocar el acceso

Puedes revocar el acceso en cualquier momento desde https://myaccount.google.com/permissions.
